# PFOI outlook contract (c1_output) — change log

| Contract | Model | Date | Change |
|---|---|---|---|
| 1.0 | pfoi-1.0.0 | 2026-10-19 | First version: `c1_output.outlook`, `c1_output.attribution`, `c1_output.history` (DDL in `components/predictive_farm_intelligence/docs/sql/c1_output_tables.sql`). |
| 1.0 (unchanged) | pfoi-1.0.0 | 2026-10-19 | Page document only (`c1_output.run_document.document`, JSON; no table columns change): adds `realised` (recorded outcomes of the forecast periods, same row shape as `actuals`, only periods complete before the last data day; display and scoring only, read after every forecast is built) and `realised_through` (last data day, or null). Older documents lack both keys; readers treat a missing key as "no realised outcomes". |
| 1.0 (unchanged) | pfoi-1.2.0-dev | 2026-10-20 | Page document only, development builds only (`build-outlook --preset ... --k / --anchor-gate / --intervals aci / --staleness`; frozen versions' documents are unchanged). Optional keys, all herd-level aggregates (docs: `components/predictive_farm_intelligence/docs/pp1_frontend_plan.md`): `record_status` (milk-record checks: freshness, completeness, plausibility, source agreement; status current / stale / withheld), `withheld` (series and periods with no published forecast, with reason code, e.g. `milk_withheld:no_trusted_recent_days`; no outlook rows exist for them), `interval_method`, `outage_simulation`, `heat` (weather only: recent THI up to the forecast date minus 6 days, and past-year climatology ahead), `repro_timing`, `generation_outcomes`, `evidence_ladder` (with a `status` per row), `feature_registry`. In `outlook`, a withheld milk series has no rows (never 0). No table columns change; readers treat a missing key as "not available for this run". |
